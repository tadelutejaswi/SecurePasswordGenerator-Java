# Secure Password Generator - Java 🔐

This is a simple **Java Console App** that generates **secure, random passwords** using `SecureRandom`. Built for learning and showcasing on your resume 🚀

---

## 💡 Features
- Strong password generation using uppercase, lowercase, numbers, and symbols
- Secure randomness using `SecureRandom` (better than `Math.random`)
- Customizable password length
- Beginner-friendly code

---

## 🖥️ How to Run

```bash
javac PasswordGenerator.java
java PasswordGenerator
